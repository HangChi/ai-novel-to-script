# 需求说明

## 背景

很多小说作者希望将自己的作品改编成剧本，但小说和剧本在表达方式上差异明显。小说重叙述、心理描写和文字氛围，剧本重场景、人物动作、对白和可拍摄性。AI Novel to Script 希望用 AI 辅助完成第一轮结构化改编，让作者更快获得可编辑的剧本初稿。

## 目标用户

- 希望将小说改编为短剧、影视剧、广播剧或舞台剧的小说作者。
- 需要快速整理故事场次、人物对白和动作线索的编剧。
- 需要批量评估小说改编潜力的内容团队。

## 核心需求

- 支持输入 3 个章节以上的小说文本。
- 自动识别章节、主要人物、场景、时间、动作、对白和旁白。
- 将小说文本转换为结构化剧本 YAML。
- 生成结果需要可读、可编辑，并能被后续校验工具验证。
- 输出应尽量忠于原文情节，避免无依据地扩写关键剧情。

## MVP 范围

- 支持纯文本输入。
- 支持同步生成一份 YAML 剧本初稿。
- 支持将当前 YAML 展示为结构化只读预览，便于快速检查标题、logline、人物、场景和 beats。
- 支持基础输入校验，例如章节数量不少于 3。
- 支持基础 YAML Schema 文档和字段说明。

## 暂不包含

- 完整的多人协作编辑。
- 商业级版权管理。
- 多语言翻译。
- 复杂分镜、镜头调度和拍摄计划生成。

## 初步验收标准

- 输入少于 3 个章节时，系统能够提示用户补充内容。
- 输入 3 个章节以上小说文本时，系统能够输出符合 Schema 的 YAML。
- YAML 至少包含剧本元信息、来源信息、人物列表、场次列表和场次内容。
- 页面能够把 YAML 映射为只读结构化视图，展示标题、logline、人物、场景和 beats。
- 用户可以复制或下载 YAML，继续人工修改。
