# 开发日志

## 2026-06-07

- 修复 Kimi-2.6 生成时因默认 `temperature=0.3` 被拒（HTTP 400 `only 1 is allowed for this model`）的问题；将 Kimi-2.6 默认 temperature 调整为 1，并同步更新 `.env.example`，仍可通过 `KIMI_TEMPERATURE` 覆盖。
- 修复远程 AI Provider 返回 HTTP 错误（如 400）时只提示 `AI provider returned HTTP 400.` 而丢弃具体原因的问题；现在会解析 Provider 返回的 JSON 或纯文本错误体，将 `Model Not Exist`、`Insufficient Balance` 等说明附加到错误信息中，并对超长内容做截断。
- 远程 AI 生成新增输出语言约束，默认自动识别中文输入并要求 DeepSeek/Kimi/GLM 输出简体中文字段值，同时保持 YAML key 为英文 Schema key。
- 前端“生成 YAML”按钮旁新增模型选择器，支持本地骨架、DeepSeek-V4-Pro、Kimi-2.6 和 GLM-4.7-FlashX，并在远程模型缺少 API Key 时提示未配置。
- 新增 `GET /api/ai/models`，返回可选模型、默认模型、base URL、配置完整性和缺失环境变量，不返回任何 API Key。
- `POST /api/scripts/generate` 支持请求体 `model_id`，可按用户选择的模型生成；`.env.example` 已补齐 DeepSeek、Kimi 和 GLM 的模型与 base URL，只保留 API Key 为空。
- 前端兼容远程 AI 返回的 JSON 风格 YAML key（如 `"script":`、`"title":`），会在展示和解析前规范化为项目统一 key 样式，避免结构化预览误报找不到 `script` 根节点。
- 修复远程 AI 返回 JSON 风格 YAML（如 `"script":`）时前端结构化预览无法识别根节点的问题；后端在返回前会将有效 AI YAML 规范化为项目统一的 `script:` 样式。
- 修复英文 `Chapter N` 小说输入通过远程 AI Provider 生成时偶发 YAML Schema 校验失败的问题；收紧远程提示词、提取真实 `script:` YAML，并清理英文智能标点乱码，确保英文样例可生成可校验的剧本 YAML。

## 2026-06-06

- 新增 `scripts/stop-local-demo.ps1`，支持停止本地演示启动的后端、前端开发服务器和相关子进程，并提供 `-DryRun` 预览。
- 新增后端命令行启动入口 `python main.py -p 8000`，固定前端开发端口为 5173，并让本地演示脚本和 E2E 显式传递前后端端口配置，避免手动启动时出现 CORS 未连接。
- 优化前端顶部 AI/后端状态展示、三栏指标对齐和剧本 YAML 标题栏操作按钮，并移除 YAML 面板中的 schema 版本徽标。
- 后端启动时支持自动读取项目根目录 `.env`、`backend/.env` 或 `AI_CONFIG_FILE` 指定的配置文件，便于通过本地文件配置 AI Provider。
- 前端顶部新增 AI Provider 状态展示，并在远程 Provider 配置缺失或不支持时提示缺失配置、禁用生成入口。
- 新增 `GET /api/ai/status`，用于查询当前 AI Provider 模式、模型、base URL、配置完整性和缺失环境变量，且不返回任何密钥。
- AI Provider 在模型首轮输出未通过 YAML Schema 校验时，会携带校验错误自动追加一次修复请求，提升远程模型输出稳定性。
- 新增 `AI_PROVIDER=deepseek` 配置入口，复用 OpenAI-compatible Chat Completions 实现，并补充 DeepSeek 环境变量示例和文档。
- 支持在结构化预览中新增、删除场景（至少保留一个场景），并即时写回 YAML。
- 支持在结构化预览中编辑、新增、删除场景的登场人物，并即时写回 YAML。
- 支持在结构化预览中编辑人物的姓名、角色、描述，并支持新增、删除人物，即时写回 YAML。
- 支持在结构化预览中编辑对白（dialogue）beat 的说话人，并即时写回 YAML。
- 补充 Playwright E2E 浏览器烟测的使用说明到 README，并与当前 E2E 实际覆盖范围对齐。
- 将剧本 YAML 面板移动到结构化预览之后，使结构化预览在三栏工作台中居中显示。
- 将工作台改为三栏布局（小说文本输入 / 结构化预览编辑 / 剧本 YAML）。
- 优化生成后工作台的滚动布局，避免长内容溢出。
- PR 6 新增结构化编辑同步状态提示，并强化校验、复制、下载复用最新 YAML 的 E2E 断言。
- PR 5 支持编辑 beat 类型和文本，并支持新增、删除 beat。
- PR 4 支持在结构化视图中编辑场景标题、地点和时间，并即时同步回 YAML。
- PR 3 支持在结构化视图中编辑剧本标题和 logline，并即时同步回 YAML，复用现有校验、复制和下载流程。
