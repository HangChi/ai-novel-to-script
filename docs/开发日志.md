### 功能与修复记录

- 新增长文本后台生成任务：前端“生成 YAML”会创建 job，通过 SSE 展示阶段进度、模型和耗时，断开时回退查询任务状态。
- 新增 `POST /api/scripts/generate/jobs`、`GET /api/scripts/generate/jobs/{job_id}` 和 `GET /api/scripts/generate/jobs/{job_id}/events`，后台任务第一版使用内存存储和单 worker 执行。
- 优化生成进度体验：前端使用阶段估算进度平滑推进，后端在 AI 生成阶段推送 `preview_yaml`，让 YAML 面板先显示骨架预览，完成后再替换为最终结果。
- 修复 Kimi-2.6 国内站 API Key 认证失败问题：默认 base URL 使用 `https://api.moonshot.cn/v1`，不再自动改写用户配置的 Moonshot 国内站或国际站地址；内置 Kimi 请求保持非 thinking 模式并固定 `temperature=0.6`，避免旧温度配置触发 API 参数错误。
- 优化远程 AI 网络错误提示，DNS、连接或超时失败会携带底层原因，不再只显示 `AI provider request failed.`。
- 修复远程 AI Provider 返回 HTTP 错误时丢弃具体原因的问题，现在会保留 Provider 返回的关键错误说明。
- 远程 AI 生成新增输出语言约束，默认自动识别中文输入并要求输出简体中文字段值，同时保持 YAML key 为英文 Schema key。
- 前端“生成 YAML”按钮旁新增模型选择器，支持本地骨架、DeepSeek-V4-Pro、Kimi-2.6 和 GLM-4.7-FlashX。
- 新增 `GET /api/ai/models`，返回可选模型、默认模型、base URL、配置完整性和缺失环境变量，不返回任何 API Key。
- `POST /api/scripts/generate` 支持请求体 `model_id`。
- 前后端兼容远程 AI 返回的 JSON 风格 YAML key，规范化为项目统一 `script:` 样式。
- 修复英文 `Chapter N` 小说输入通过远程 AI Provider 生成时偶发 Schema 校验失败的问题。

- 新增后端命令行启动入口 `python main.py -p 8000`，支持 `--frontend-port` 和 `--reload`。

- AI Provider 在首轮输出未通过 YAML Schema 校验时，会携带校验错误自动追加一次修复请求。

- 支持在结构化预览中编辑对白 beat 的说话人。
- 支持编辑 beat 类型和文本，并支持新增、删除 beat。
- 支持编辑剧本标题、logline、场景标题、地点和时间，并即时同步回 YAML。
- 新增 YAML 结构化预览，可将当前 YAML 映射为标题、logline、人物、场景和 beats 视图。
