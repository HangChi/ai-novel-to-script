- 新增可配置 AI Provider，默认 `local` 返回 YAML 骨架，可通过 OpenAI-compatible Provider 将骨架升级为 AI 改编结果。
- 前端接入 YAML Schema 校验入口，支持展示校验通过状态、错误路径和错误信息。
- 前端新增 YAML 一键复制，复制内容与当前预览或编辑后的 YAML 保持一致。
