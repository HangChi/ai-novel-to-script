# 接口文档

## 当前状态

项目已搭建基础后端服务，并实现内部小说章节解析、基础校验、剧本 YAML 初稿生成接口、YAML 校验接口和可配置 AI Provider。

当前已实现：

```http
GET /api/health
POST /api/scripts/generate
POST /api/scripts/validate
```

响应体：

```json
{
  "status": "ok"
}
```

章节解析能力目前作为后端内部模块提供，不单独暴露正式 HTTP API。`POST /api/scripts/generate` 会复用该模块完成输入校验，先生成符合当前 Schema 的 YAML 骨架，再根据 AI Provider 配置决定是否调用 AI 改编。

## 生成剧本

```http
POST /api/scripts/generate
```

将 3 个章节以上的小说纯文本转换为可编辑的剧本 YAML 初稿。默认 `AI_PROVIDER=local` 时返回结构化骨架；配置 `AI_PROVIDER=deepseek` 后，会调用 DeepSeek OpenAI-compatible Chat Completions 接口进行改编；配置 `AI_PROVIDER=openai` 后，会调用通用 OpenAI-compatible Provider。远程 Provider 返回结果会在响应前校验 YAML Schema。

### AI Provider 配置

- `AI_PROVIDER=local`：默认模式，不需要密钥，返回稳定 YAML 骨架。
- `AI_PROVIDER=deepseek`：需要 `DEEPSEEK_API_KEY`，默认 `DEEPSEEK_MODEL=deepseek-v4-flash`，默认 `DEEPSEEK_BASE_URL=https://api.deepseek.com`。
- `AI_PROVIDER=openai`：需要 `OPENAI_API_KEY` 和 `OPENAI_MODEL`，默认 `OPENAI_BASE_URL=https://api.openai.com/v1`。

API Key 仅由后端环境变量读取，不通过请求体传入，也不会出现在生成接口响应中。

### 请求体

```json
{
  "title": "示例小说",
  "content": "第 1 章 ...\n第 2 章 ...\n第 3 章 ...",
  "output_format": "yaml"
}
```

### 响应体

```json
{
  "status": "completed",
  "schema_version": "0.1.0",
  "yaml": "script:\n  schema_version: 0.1.0\n  title: 示例小说\n  ..."
}
```

### 错误响应

```json
{
  "detail": {
    "code": "INVALID_CHAPTER_COUNT",
    "message": "小说章节数量不能少于 3 章。"
  }
}
```

## 校验剧本 YAML

```http
POST /api/scripts/validate
```

校验剧本 YAML 是否符合当前 `0.1.0` Schema 的基础结构。该接口不会修改 YAML 内容，只返回校验结果和错误列表。

### 请求体

```json
{
  "yaml": "script:\n  title: 示例小说\n"
}
```

> `yaml` 是唯一必填字段。Schema 版本不通过请求字段传入，而是由 YAML 内部的 `script.schema_version` 参与校验（必须为 `0.1.0`）。

### 响应体

```json
{
  "valid": true,
  "errors": []
}
```

### 校验失败响应

```json
{
  "valid": false,
  "errors": [
    {
      "code": "YAML_VALIDATION_FAILED",
      "path": "script.scenes[0].beats[0].type",
      "message": "must be action, dialogue, narration, or transition."
    }
  ]
}
```

### 当前校验范围

- YAML 语法必须可解析。
- 顶层必须包含 `script` 映射。
- `schema_version` 必须为 `0.1.0`。
- `title`、`logline`、`source`、`characters`、`scenes` 必须存在且类型正确。
- `source.type` 必须为 `novel`，`chapters_count` 不少于 3。
- `characters` 必须是列表，人物项需包含字符串类型的 `id` 和 `name`。
- `scenes` 必须是非空列表，场次项需包含 `id`、`title`、`source_chapter`、`location`、`time`、`characters` 和 `beats`。
- `beats` 必须是非空列表，`type` 仅支持 `action`、`dialogue`、`narration`、`transition`。

## 错误码

- `INVALID_CHAPTER_COUNT`：小说章节少于 3 个。
- `INVALID_INPUT`：输入文本为空、格式不可识别、章节正文为空或输出格式暂不支持。
- `AI_GENERATION_FAILED`：AI Provider 配置错误、调用失败或返回内容未通过 YAML Schema 校验。
- `YAML_VALIDATION_FAILED`：YAML 语法错误或内容不符合 Schema。
