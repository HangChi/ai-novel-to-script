# 接口文档

## 当前状态

项目已搭建基础后端服务，并实现内部小说章节解析与基础校验模块。以下生成和校验接口仍为 API 初稿，用于指导后续开发。

当前已实现：

```http
GET /api/health
```

响应体：

```json
{
  "status": "ok"
}
```

章节解析能力目前作为后端内部模块提供，暂不暴露正式 HTTP API。后续 `POST /api/scripts/generate` 会复用该模块完成输入校验。

## 生成剧本

```http
POST /api/scripts/generate
```

### 请求体

```json
{
  "title": "示例小说",
  "content": "第 1 章 ...\n第 2 章 ...\n第 3 章 ...",
  "output_format": "yaml"
}
```

### 响应体

```json
{
  "status": "completed",
  "schema_version": "0.1.0",
  "yaml": "script:\n  title: 示例小说\n"
}
```

## 校验剧本 YAML

```http
POST /api/scripts/validate
```

### 请求体

```json
{
  "schema_version": "0.1.0",
  "yaml": "script:\n  title: 示例小说\n"
}
```

### 响应体

```json
{
  "valid": true,
  "errors": []
}
```

## 错误码草案

- `INVALID_CHAPTER_COUNT`：小说章节少于 3 个。
- `INVALID_INPUT`：输入文本为空或格式不可识别。
- `AI_GENERATION_FAILED`：AI 生成失败。
- `YAML_VALIDATION_FAILED`：生成内容不符合 Schema。
