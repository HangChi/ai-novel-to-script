# 接口文档

## 当前状态

项目已搭建基础后端服务，并实现内部小说章节解析、基础校验和剧本 YAML 初稿生成接口。

当前已实现：

```http
GET /api/health
POST /api/scripts/generate
```

响应体：

```json
{
  "status": "ok"
}
```

章节解析能力目前作为后端内部模块提供，不单独暴露正式 HTTP API。`POST /api/scripts/generate` 会复用该模块完成输入校验，并返回符合当前 Schema 的 YAML 初稿骨架。

## 生成剧本

```http
POST /api/scripts/generate
```

将 3 个章节以上的小说纯文本转换为可编辑的剧本 YAML 初稿。本接口当前生成的是结构化骨架，暂未接入 AI 改编能力。

### 请求体

```json
{
  "title": "示例小说",
  "content": "第 1 章 ...\n第 2 章 ...\n第 3 章 ...",
  "output_format": "yaml"
}
```

### 响应体

```json
{
  "status": "completed",
  "schema_version": "0.1.0",
  "yaml": "script:\n  schema_version: 0.1.0\n  title: 示例小说\n  ..."
}
```

### 错误响应

```json
{
  "detail": {
    "code": "INVALID_CHAPTER_COUNT",
    "message": "小说章节数量不能少于 3 章。"
  }
}
```

## 校验剧本 YAML

```http
POST /api/scripts/validate
```

### 请求体

```json
{
  "schema_version": "0.1.0",
  "yaml": "script:\n  title: 示例小说\n"
}
```

### 响应体

```json
{
  "valid": true,
  "errors": []
}
```

## 错误码草案

- `INVALID_CHAPTER_COUNT`：小说章节少于 3 个。
- `INVALID_INPUT`：输入文本为空、格式不可识别、章节正文为空或输出格式暂不支持。
- `AI_GENERATION_FAILED`：AI 生成失败。
- `YAML_VALIDATION_FAILED`：生成内容不符合 Schema。
