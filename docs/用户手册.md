# 用户手册

## 产品状态

当前版本提供一个本地剧本改编工作台。用户可以导入或粘贴小说文本，选择本地骨架或远程 AI 模型后台生成剧本 YAML，并在生成期间查看阶段估算进度、模型和耗时。系统会先显示 YAML 骨架预览，最终模型结果校验通过后再替换为完整剧本 YAML。生成完成后，可以在结构化预览中编辑标题、人物、场景和 beats，并对最终 YAML 进行校验、复制或下载。

默认“本地骨架”不需要 API Key，适合演示和测试。远程模型需要先在 `.env` 或系统环境变量中配置对应密钥。

## 快速开始

1. 启动后端和前端。
2. 打开 `http://127.0.0.1:5173`。
3. 准备至少 3 个章节的小说文本。
4. 粘贴文本，或点击“导入文件”选择 `.txt` / `.md` 文件。
5. 查看页面顶部后端和 AI 状态。
6. 在“生成 YAML”旁选择模型。
7. 点击“生成 YAML”。
8. 等待进度显示完成；如果 SSE 连接中断，页面会自动回退查询任务状态。
9. 在结构化预览中检查和编辑内容。
10. 点击“校验 YAML”。
11. 点击“复制 YAML”或“下载 YAML”导出结果。

## 示例演示

仓库内置示例：

- 小说文本：`docs/examples/rain-letter-novel.txt`
- 期望骨架：`docs/examples/rain-letter-script.yaml`

推荐演示流程：

1. 点击“导入文件”并选择示例小说。
2. 保持模型为“本地骨架”。
3. 点击“生成 YAML”，观察进度条完成。
4. 修改剧本标题、logline、一个人物名称、一个场景地点和一个 beat 文本。
5. 看到结构化修改已同步到 YAML 后，点击“校验 YAML”。
6. 复制或下载 YAML。

## 输入建议

- 至少提供 3 个完整章节。
- 尽量保留章节标题。
- 人物首次登场时保留上下文，有助于 AI 提取人物关系。
- 不建议只提供零散片段；片段缺少叙事上下文，生成结果会不稳定。
- 本地导入只读取浏览器中的文本内容，不会单独保存原始文件。

## 模型选择

### 本地骨架

“本地骨架”是默认模型，不需要密钥，不访问外部服务。它会把章节转换成稳定 YAML 结构，并保留原文到 `narration` beat 中。

### 远程模型

当前模型下拉支持：

- DeepSeek-V4-Pro
- Kimi-2.6
- GLM-4.7-FlashX

远程模型需要在 `.env` 中填写对应 API Key，并重启后端。缺少密钥的模型会显示未配置，页面不会发起无效生成请求。

### 输出语言

默认 `AI_OUTPUT_LANGUAGE=auto`。中文小说会要求远程模型输出简体中文字段值，同时保持 YAML key 为英文 Schema key。

## 结构化预览

结构化预览会读取当前 YAML，并展示可编辑内容：

- 剧本标题和 logline。
- 人物列表，包括姓名、角色和描述。
- 场景列表，包括标题、来源章节、地点、时间和登场人物。
- 场景 beats，包括类型、文本和对白说话人。

当前支持：

- 新增、编辑、删除人物。
- 新增、编辑、删除场景，并至少保留一个场景。
- 新增、编辑、删除场景登场人物。
- 新增、编辑、删除 beat。
- 编辑对白 beat 的说话人。

结构化编辑和在线 YAML 编辑共用同一份 YAML。看到同步提示后，可以直接校验、复制或下载。

## 生成进度

点击“生成 YAML”后，页面会先创建后台任务，然后显示当前阶段。进度百分比是阶段估算，不代表模型逐 token 输出速度：

- 排队中：任务已创建，等待后端执行。
- 解析章节：后端正在识别章节标题和正文。
- 构建骨架：后端正在生成基础 YAML。
- AI 生成：正在调用本地骨架或远程模型。
- 校验 YAML：正在检查模型输出是否符合 Schema。
- 已完成或生成失败：任务进入终态。

YAML 面板会在“AI 生成”阶段先展示后端生成的骨架预览；远程模型完整返回并通过校验后，页面会用最终 YAML 替换该预览。如果远程模型失败，页面仍可保留骨架预览作为可编辑起点。

第一版后台任务只保存在后端内存中，刷新页面不会显示历史任务；后端重启后，未完成任务会丢失。

## YAML 编辑与校验

YAML 面板支持在线编辑。适合进行更细的字段调整，或复制到其它工具继续处理。

点击“校验 YAML”后，系统会检查：

- YAML 语法是否可解析。
- 是否包含 `script` 根节点。
- Schema 版本是否为 `0.1.0`。
- 必填字段是否存在且类型正确。
- 场景和 beat 是否满足基础结构要求。

如果校验失败，页面会显示错误路径和说明，例如 `script.scenes[0].beats[0].type`。

## 导出

- “复制 YAML”会复制页面当前最新 YAML。
- “下载 YAML”会下载 `script-draft.yaml`。
- 导出的内容包含结构化预览和在线 YAML 编辑后的最新修改。

## 本地演示启动与停止

启动：

```powershell
.\scripts\start-local-demo.ps1
```

停止：

```powershell
.\scripts\stop-local-demo.ps1
```

预览停止范围：

```powershell
.\scripts\stop-local-demo.ps1 -DryRun
```

如果使用自定义端口：

```powershell
.\scripts\start-local-demo.ps1 -BackendPort 8001 -FrontendPort 5174
.\scripts\stop-local-demo.ps1 -Ports 8001,5174
```

## 常见问题

### 为什么要求至少 3 个章节？

少于 3 个章节时，系统难以稳定判断主要人物、故事节奏和场景关系。至少 3 个章节可以提供更可靠的上下文。

### 页面提示远程模型未配置怎么办？

复制 `.env.example` 为 `.env`，填写对应模型的 API Key，然后重启后端。状态接口不会返回密钥值，只会提示缺少哪些配置项。

### YAML 可以手动编辑吗？

可以。YAML 的设计目标就是便于阅读、编辑和后续校验。手动编辑后建议点击“校验 YAML”。

### 结构化预览和 YAML 面板谁是最终结果？

两者共用同一份 YAML。结构化预览修改会写回 YAML，YAML 面板修改后结构化预览会尝试重新解析并刷新。

### 为什么点击生成后返回 AI 错误？

常见原因包括 API Key 缺失、模型名称错误、账号余额不足、远程服务返回 400/401/429/500，或远程模型输出无法通过 Schema 校验。错误信息会尽量保留 Provider 返回的关键说明。

### 生成进度连接断开怎么办？

页面会自动改用任务状态接口查询最终结果。如果后端服务被重启，内存任务会丢失，需要重新点击“生成 YAML”。

### 页面显示后端未连接怎么办？

确认后端健康检查 `http://127.0.0.1:8000/api/health` 可访问。如果前端不是 `5173` 端口启动，需要后端同步传入 `--frontend-port`。
