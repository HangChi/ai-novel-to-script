# 用户手册

## 当前状态

产品尚未实现，以下为预期使用流程。

## 使用流程

1. 准备至少 3 个章节的小说文本。
2. 在工具中粘贴文本或上传文件。
3. 点击生成剧本。
4. 查看系统生成的 YAML 剧本初稿。
5. 根据需要编辑人物、场景、对白和动作。
6. 复制或导出 YAML，用于后续剧本打磨。

## 输入建议

- 尽量保留章节标题。
- 不要只提供片段，至少提供 3 个完整章节。
- 如果小说中人物较多，建议保留人物首次登场时的上下文。

## 输出说明

生成结果是剧本初稿，不是最终定稿。作者仍需要根据创作意图调整节奏、对白、场次顺序和人物弧光。

## 常见问题

### 为什么要求至少 3 个章节？

少于 3 个章节时，AI 很难稳定判断主要人物、故事节奏和场景关系。至少 3 个章节可以提供更可靠的上下文。

### YAML 可以手动编辑吗？

可以。YAML 的设计目标就是便于阅读、编辑和后续校验。
