# 部署文档

## 当前状态

项目已搭建基础前后端服务。当前阶段支持本地分别启动前端开发服务器和后端 API 服务，`docker-compose.yml` 仍保留为后续容器化编排占位。

## 规划中的部署方式

- 本地开发：通过前端开发服务器和后端 API 服务分别启动。
- 容器化部署：通过 `docker-compose.yml` 统一编排前端、后端和可选数据库。
- 生产部署：根据实际技术栈选择云服务器、容器平台或托管服务。

## 本地开发启动

### 后端 API

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m uvicorn app.main:app --reload --port 8000
```

健康检查：

```text
http://127.0.0.1:8000/api/health
```

### 前端

```powershell
cd frontend
npm install
npm run dev
```

默认访问地址：

```text
http://127.0.0.1:5173
```

## 环境变量规划

```text
AI_PROVIDER=local
OPENAI_API_KEY=
OPENAI_MODEL=
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_TEMPERATURE=0.3
AI_PROVIDER_TIMEOUT_SECONDS=60
BACKEND_PORT=
FRONTEND_PORT=
DATABASE_URL=
```

### AI Provider

后端默认使用 `AI_PROVIDER=local`，不会访问外部服务，会直接返回结构化 YAML 骨架。需要启用 AI 改编时，可设置：

```powershell
$env:AI_PROVIDER="openai"
$env:OPENAI_API_KEY="你的 API Key"
$env:OPENAI_MODEL="你的模型名称"
```

`OPENAI_BASE_URL` 默认为 `https://api.openai.com/v1`，也可以替换为兼容 Chat Completions 的服务地址。
