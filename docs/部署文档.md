# 部署文档

## 当前状态

项目已搭建基础前后端服务。当前阶段支持本地分别启动前端开发服务器和后端 API 服务，`docker-compose.yml` 仍保留为后续容器化编排占位。

## 规划中的部署方式

- 本地开发：通过前端开发服务器和后端 API 服务分别启动。
- 容器化部署：通过 `docker-compose.yml` 统一编排前端、后端和可选数据库。
- 生产部署：根据实际技术栈选择云服务器、容器平台或托管服务。

## 本地开发启动

### 后端 API

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py -p 8000 --reload
```

健康检查：

```text
http://127.0.0.1:8000/api/health
```

### 前端

```powershell
cd frontend
npm install
npm run dev
```

默认访问地址：

```text
http://127.0.0.1:5173
```

`npm run dev` 默认固定 `5173` 端口，并开启 strict port。若需要换端口，后端启动时同步传入允许的前端端口：

```powershell
# 后端
cd backend
.\.venv\Scripts\python main.py -p 8000 --frontend-port 5174

# 前端
cd frontend
$env:VITE_API_BASE_URL="http://127.0.0.1:8000"
npm run dev -- --port 5174
```

### 一键本地演示

项目根目录提供本地演示脚本：

```powershell
.\scripts\start-local-demo.ps1
```

脚本会复用或启动后端 API 与前端开发服务器，并输出示例输入路径和页面演示步骤。需要同时运行演示烟测时，可使用：

```powershell
.\scripts\start-local-demo.ps1 -RunSmoke
```

停止本地演示进程：

```powershell
.\scripts\stop-local-demo.ps1
```

停止前可先查看匹配到的进程：

```powershell
.\scripts\stop-local-demo.ps1 -DryRun
```

如果本地演示使用了自定义端口，请传入对应端口：

```powershell
.\scripts\stop-local-demo.ps1 -Ports 8001,5174
```

## 配置文件与环境变量

后端启动时会自动读取项目根目录 `.env` 和 `backend/.env`，适合本地开发和演示配置。真实密钥只应写入 `.env` 这类本地配置文件；`.env` 与 `.env.*` 已被 `.gitignore` 忽略。

首次配置可复制示例：

```powershell
Copy-Item .env.example .env
```

配置项示例：

```text
AI_PROVIDER=local
OPENAI_API_KEY=
OPENAI_MODEL=
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_TEMPERATURE=0.3
DEEPSEEK_API_KEY=
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_TEMPERATURE=0.3
AI_PROVIDER_TIMEOUT_SECONDS=60
BACKEND_PORT=
FRONTEND_PORT=
DATABASE_URL=
```

配置文件只会填充缺失的环境变量；如果系统环境变量已存在，会优先使用系统环境变量。需要使用其它配置文件路径时，可在启动后端前设置 `AI_CONFIG_FILE` 指向该文件。

### AI Provider

后端默认使用 `AI_PROVIDER=local`，不会访问外部服务，会直接返回结构化 YAML 骨架。需要启用 DeepSeek 改编时，可在 `.env` 中设置：

```text
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的 DeepSeek API Key
DEEPSEEK_MODEL=deepseek-v4-flash
```

`DEEPSEEK_BASE_URL` 默认为 `https://api.deepseek.com`，`DEEPSEEK_MODEL` 默认使用 `deepseek-v4-flash`，也可以按部署需要改为 `deepseek-v4-pro`。

需要启用通用 OpenAI-compatible Provider 时，可在 `.env` 中设置：

```text
AI_PROVIDER=openai
OPENAI_API_KEY=你的 API Key
OPENAI_MODEL=你的模型名称
```

`OPENAI_BASE_URL` 默认为 `https://api.openai.com/v1`，也可以替换为兼容 Chat Completions 的服务地址。
