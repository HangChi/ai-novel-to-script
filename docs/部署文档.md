# 部署文档

## 当前状态

项目暂未实现前端和后端服务，因此当前部署文档只保留基础规划。

## 规划中的部署方式

- 本地开发：通过前端开发服务器和后端 API 服务分别启动。
- 容器化部署：通过 `docker-compose.yml` 统一编排前端、后端和可选数据库。
- 生产部署：根据实际技术栈选择云服务器、容器平台或托管服务。

## 环境变量规划

```text
AI_PROVIDER=
AI_API_KEY=
BACKEND_PORT=
FRONTEND_PORT=
DATABASE_URL=
```

## Docker Compose

当前 `docker-compose.yml` 是占位配置。前后端代码落地后，需要补充具体镜像、构建路径、端口和环境变量。
