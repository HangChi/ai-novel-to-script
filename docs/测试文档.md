# 测试文档

## 测试目标

测试重点是保证小说输入能稳定解析，剧本 YAML 符合 Schema，前端结构化编辑会同步到导出内容，并且默认本地模式可以在无外部 API Key 的情况下复现完整演示流程。

## 测试范围

- 章节解析和章节数量校验。
- 剧本 YAML 骨架生成。
- OpenAI-compatible Provider 输出清洗、修复重试和错误映射。
- YAML Schema 校验。
- AI Provider 状态和模型列表。
- 后台生成任务、SSE 进度流、任务失败状态和完成后结果查询。
- 前端输入、文件导入、模型选择、生成、结构化预览、局部编辑、同步提示、校验、复制和下载。
- 本地演示启动、停止和浏览器端到端烟测。

## 推荐验证命令

后端测试：

```powershell
cd backend
.\.venv\Scripts\python -m pytest
```

前端构建：

```powershell
cd frontend
npm run build
```

浏览器烟测：

```powershell
.\scripts\start-local-demo.ps1 -RunSmoke
```

或：

```powershell
cd frontend
npm run smoke:e2e
```

首次运行烟测前需要：

```powershell
cd frontend
npm run e2e:install
```

## 已覆盖的自动化测试

- 章节解析支持 `第 1 章`、`第一章`、`第001章`、Markdown 标题、`第1回`、`Chapter 1`、`1. 初遇` 等格式。
- 正文中的章节字样不会被误判为章节标题。
- 少于 3 个章节、空文本、无法识别章节标题和章节正文为空时会返回明确错误。
- 章节解析结果可转换为包含 `script`、`source`、`characters`、`scenes` 和 `beats` 的 YAML。
- `POST /api/scripts/generate` 可生成 YAML，并返回 `status`、`schema_version` 和 `yaml`。
- `POST /api/scripts/generate` 支持 `model_id`，并会拒绝不支持的模型 id。
- `POST /api/scripts/generate/jobs` 可创建后台任务，并返回 `job_id`、`status_url` 和 `events_url`。
- `GET /api/scripts/generate/jobs/{job_id}` 可读取 queued/running/completed/failed 状态，完成后返回 YAML。
- `GET /api/scripts/generate/jobs/{job_id}/events` 至少输出 `job.status` 和终态事件。
- 后台任务进入 AI 生成阶段后可返回 `preview_yaml`，前端可先展示 YAML 骨架预览。
- 后台任务中的章节解析错误会进入 `failed`，并保留业务错误码。
- 后台任务中的 AI Provider 异常会进入 `failed`，并保留 `AI_GENERATION_FAILED` 和骨架预览。
- `POST /api/scripts/validate` 可校验语法错误、缺失字段和非法 beat 类型。
- 配置文件加载覆盖 `.env` 键值读取、引号解析、`AI_CONFIG_FILE` 指定路径和系统环境变量优先级。
- 后端启动器覆盖 `python main.py -p <port>`、`--frontend-port` 和 `--reload` 参数。
- AI Provider 默认使用 `local`，后端测试不会访问外部服务。
- OpenAI-compatible Provider 覆盖配置读取、Markdown YAML 代码块提取、提示词约束、Schema 校验失败、一次修复重试和接口错误映射。
- 远程 AI 返回说明文字、代码块、智能标点乱码、C1 控制字符或 JSON 风格 YAML key 时，系统会提取并规范化真实 YAML。
- `GET /api/ai/status` 覆盖默认 local 状态、远程配置状态和密钥不泄露断言。
- `GET /api/ai/models` 覆盖本地骨架、DeepSeek-V4-Pro、Kimi-2.6、GLM-4.7-FlashX、缺失 API Key 提示和密钥不泄露断言。
- 示例文本 `docs/examples/rain-letter-novel.txt` 生成的 YAML 必须通过后端 Schema 校验。
- 浏览器 E2E 覆盖打开页面、AI 状态、导入示例、阶段估算进度、生成 YAML、结构化预览、结构化编辑、同步提示、校验、复制和下载。
- Playwright 缺少依赖或 Chromium 时，烟测会失败并提示先安装依赖。
