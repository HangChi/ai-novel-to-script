# 测试文档

## 测试目标

测试重点是确保小说输入可以被稳定解析，并且输出 YAML 符合 Schema，便于作者继续编辑和后续工具处理。

## 测试范围

- 章节数量校验。
- 章节解析准确性。
- AI 输出结构完整性。
- YAML 语法校验。
- YAML Schema 校验。
- 前端输入、生成、展示和导出流程。

## 初步测试用例

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| T001 | 输入少于 3 个章节 | 返回章节数量不足提示 |
| T002 | 输入 3 个标准章节 | 成功生成 YAML |
| T003 | 输入包含大量心理描写 | 转换为动作、旁白或对白 |
| T004 | AI 输出缺少必填字段 | 校验失败并提示修复 |
| T005 | YAML 中包含非法结构 | 返回 Schema 校验错误 |
